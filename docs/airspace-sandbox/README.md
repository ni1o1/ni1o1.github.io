# 低空空域形态与外部性沙盘

合作者原先发布在 **https://ni1o1.github.io/airspace-sandbox/**（源码在 `ni1o1/ni1o1.github.io` 的 `docs/airspace-sandbox/`，**不在**本仓库的 git 历史上）。本目录是从该站点拉回的副本，并接上了新的容量航线与 SZU 噪声。

## 一种叠加

沙盘现在只有**一套**过境探索：从 **800 m** 外缘对边进场，用侧向净空、纵向净空和机间距生成可飞体块与航线。

| 旋钮 | 作用 |
|---|---|
| **侧向净空** | 离墙的水平距离。大了就挤掉街道缝。 |
| **纵向净空** | 屋顶以上还要再留的高度。大了就不能抄屋顶。 |
| **机间距** | 任意两架飞机的三维距离（含不同高度、不同航线）。加严时留下的航线是宽松时的子集。 |
| **800 m 边缘入口** | 每边入口个数。先给每个开口一个门，再往最大空隙里加。加入口只会加密或保持，不会把已有门挤掉。 |

预设：**街道穿行** = 侧向 10 m / 纵向 100 m；**屋顶飞越** = 侧向 100 m / 纵向 10 m；**对称 5 m** = 两者都是 5 m。

蓝色体块默认打开，在 Web Worker 里重建，不堵主线程。航线页可筛 **东西向 / 南北向**；三维打包会把两个方向交错留下。影响页四通道（噪声含一阶地面反射、坠落、隐私、视觉）按**当前航线**做浏览器粗估，调旋钮和方向会重算；着色和航线带子可以同时开。回放窗口为 **1 小时**；通行能力按当前机间距、走廊条数和 22 m/s 巡航换算成架次/时，飞机仍按真实过境时间绕圈，不会把一趟拉成一小时。

旧的三个模式（交互航线 / 容量排班 / 净空规则）和独立 `policy-gallery.html` 不再作为入口。法规条款对照仍在 `DOC/记录/53-无人机政策距离条款对照.md`。

噪声 v2 与四通道 DDA **不要混图例**：前者是面片等效连续声级，后者是体素 `B_noise/privacy/visual/groundrisk`。浏览器里**不算**噪声 v2。OH 15_0 读 `data/precomputed/hk15-noise-v2.json`；54_29 QC 读 `hk54-noise-v2.json`。打包：`scripts/pack_sandbox_noise_v2.py`。

## 怎么打开

不要 `file://`（ES 模块 / fetch 会失败）。在本目录：

```bash
python3 -m http.server 8767
```

打开 http://127.0.0.1:8767/ （换代码后请强制刷新）。

穿墙解释页：[why-wall-clip.html](http://127.0.0.1:8767/why-wall-clip.html)。独立 `policy-gallery.html` 仍在目录里，但已没有 UI 入口。

默认地块是 **Hong Kong OH 15_0**。打开后先看到侧向/纵向净空旋钮和蓝色可飞体块；航线从 800 m 外缘对穿。54_29 仍在列表里作噪声 v2 QC。

## 交互布局（2026-09-13）

- 左侧为「航线」「影响」。航线页里两个 sheet：净空规则（侧向/纵向/机间距/800 m 入口）和高度地图。
- 高度地图是选层入口：默认总览，点击卡片放大并筛选该层；左右切层，「返回」恢复总览。
- 三维航线按高度着色。蓝色体块默认打开，随净空旋钮重算。
- 右上角将复位、俯视、侧视与可展开设置合为一个面板，设置内分图层（含透明度）、视角、光照。
- 影响页四通道按当前航线粗估；机间距为三维约束。

# 低空空域形态与外部性沙盘

合作者原先发布在 **https://ni1o1.github.io/airspace-sandbox/**（源码在 `ni1o1/ni1o1.github.io` 的 `docs/airspace-sandbox/`，**不在**本仓库的 git 历史上）。本目录是从该站点拉回的副本，并接上了新的容量航线与 SZU 噪声。

## 三种叠加

| 模式 | 航线 | 外部性叠加 |
|---|---|---|
| **交互航线** | 从 **800 m** 缓冲圈外缘进场，只连东西 / 南北对边 | 页内简化核（**不是论文数字**） |
| **容量排班 + 噪声 v2**（默认，OH 15_0） | Churui / uavcap 全方向排班航线 | 预计算面片 **L_Aeq**（iso / dir / refl） |
| **Hong Kong · 54_29 (noise v2)** | 800 m 探针；障碍来自 5 m 体素外表面 | 形态探针流量下的面片 **L_Aeq** |

噪声 v2 与四通道 DDA **不要混图例**：前者是面片等效连续声级，后者是体素 `B_noise/privacy/visual/groundrisk`。浏览器里**不算**噪声 v2。OH 15_0 读 `data/precomputed/hk15-noise-v2.json`；54_29 QC 读 `hk54-noise-v2.json`。打包：`scripts/pack_sandbox_noise_v2.py`。

## 怎么打开

不要 `file://`（ES 模块 / fetch 会失败）。在本目录：

```bash
python3 -m http.server 8767
```

打开 http://127.0.0.1:8767/ （换代码后请强制刷新）。

默认地块是 **Hong Kong OH 15_0**（容量航线 + 噪声 v2，halo 建筑保留）。选「容量排班」后右下角会播放这一小时里的飞机（排班记录 22,401 架次，默认 5×；稳定容量为 22,320 架次/时）。54_29 仍在列表里作 QC。

## 交互布局（2026-09-08）

- 左侧为「航线」「影响」，全局模式切换位于街区选择下方。
- 高度地图是唯一选层入口：默认总览，点击卡片放大并筛选该层；左右切层，「返回」恢复总览和全部高度，保留方向选择。
- 容量排班的方向筛选位于地图底部，与地图蓝线、三维航线和飞机同步。「全部」为 12 类方向、240 条排班航线，「对穿」限定东西/南北对向、80 条。无容量数据的场景禁用容量选项。
- 仅显示符合高度与方向筛选的飞机和尾迹；已移除航线聚焦和其余飞机淡出。所有无人机使用统一的 0.32 缩放。
- 地图蓝线保持清晰；三维航线按高度着色。透明度直接更新材质，不重新计算路径或重建几何。交互航线和容量排班均默认 20%，各自记忆本次打开期间的手动调整。
- 右上角将复位、俯视、侧视与可展开设置合为一个面板，设置内分图层（含透明度）、视角、光照。支持 Escape 收起，隐藏控件退出键盘焦点。
- 面板无纵向滚动，左侧把手采用 420 ms 侧滑动画，画布跟随边缘调整；窄屏默认收起。高度边界默认关闭。
- 影响视图中，加载成功的体素结果替代重复白模，防止遮挡；普通白模街区关闭影响后恢复白模，没有体素结果则保留原显示。54_29 专用体素场景仍使用体素模型。
- 噪声 v2 是原情景整小时预计算结果，回放和航线筛选不重算噪声；页面保留控件、数据和色标，删除重复页脚、尺寸标注与冗长说明。

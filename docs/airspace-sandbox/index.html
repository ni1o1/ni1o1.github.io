侧向 = 离墙要留多远；纵向 = 屋顶上面还要再留多高。机间距是任意两架飞机的三维距离：不同高度、不同航线都算。间距加严时留下的航线是宽松时的子集。入口先占每个开口，再填最大空隙；加入口不会把已有航线挤掉。

模型噪声

按当前航线做浏览器粗估，用来看空间分布，不是论文定量结果。噪声通道含一阶地面反射。着色和航线带子可以同时开。
